# 判断链：记成哪一块

> 走到 M4 才读这一份。它只回答一个问题：**这次留下的东西，记成哪一块。**
> 一次走链产出一条记忆；同一件事可以走多次。

## 入口

```
Q1  这条经验指向未来?（承诺 / 待办 / 还没定）   y→不记（归调度，不归记忆）      n→Q2
Q2  它来自用户对某个产物的评价?                认可→T   否定→看下一行           n→Q3
     └ 否定再问：用户事先说过这个要求吗?
          说过 → C（判断失误，我该知道）
          没说过 → 不是纠错：用户没说，缺的是信息 → 写 K（事实/默认值）+ 硬规则
Q3  它是个可重复执行的动作?                    y→Q3a    n→Q4
Q3a 已有现成工具?                            y→读说明·用它                 n→Q3b
Q3b 输入输出能说清且无「看情况」?              y→TL     n→Q4
Q4  要推翻它，需先知道为什么这么定?            y→D      n→K
```

> Q3 问的是**这条经验本身是不是一个动作**，不是「我刚才有没有动手」——走到 M4 时手已经动过了。

## 五个叶子

```
K  认知  → 读 meta/cognition.md   写：结构与约束 / 怎么验证还成立 / 来源
D  决策  → 读 meta/decision.md    写：定了什么 / 为什么（取舍·判定·外部约束）/ 何时该重考虑
T  品味  → 读 meta/taste.md       写：对象 / 方向 / 理由 / 边界 / 产物指针
C  纠错  → 读 meta/correction.md  写：症状 / 触发 / 检查（动作）/ 止损
TL 工具  → 读 meta/tool.md        写：做什么 / 何时用 / 怎么调 / 会改什么 / 怎么看结果 / 失败怎么办
```

## 用哪个工具写

```
记录（五块）  → memory_write(kind, title, content, scope)
硬规则/AGENT  → doc_write(path, content)
临时答案      → memory_write(kind: "pending")
走过的路径    → path_record(line)
```

**数据根在 workspace 之外**，你自己的文件工具写不进去——必须走这几个工具。

## 落在哪一层

```
内容里出现具体项目名   → scope=project（只对这个项目）
内容里不出现项目名     → scope=scenario（所有项目通用）
```

例：「以后所有项目都用 pnpm」→ 场景级；「A 项目的测试要带 --filter」→ 项目级。

## 硬规则不进记录，进 rules.md

如果这条记忆的违反后果**不可逆**，或者**会反复执行且不需要再解释**：

→ 用 `doc_write` 在**同一层的 `rules.md` 里加一条**，不只写成记录。

`rules.md` 是 M1 交付的东西——它在动手前就会送到眼前。记录不会。**看不见的约束等于不存在。**

一条硬规则的形状：

```
- 出稿前 grep 一遍 import，确认组件库版本是 v3.2
  来源：scenarios/design/records/decision/组件版本.md
```

「来源」那一行不能省：规则是「做什么」，来源是「为什么」。规则被质疑时要能追回去。

## 任何节点答不出来

**任何 `else` 出口 → 退回散文心法自己判断**，并把「我凭什么这么判」记一句。

这句掉落记录是链生长的原料：**同一个点掉两次，才允许给它加分支。**
